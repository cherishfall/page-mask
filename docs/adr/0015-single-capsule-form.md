# 胶囊单一形态：面具主钮、自由定位、把手悬停显隐

日期：2026-11-08 · 状态：已采纳 · 修订：design.md 版本切分中 0.6.x 引入的双形态（#78/#79） · 相关：ADR-0013、ADR-0014、issue#135

## 背景

0.8.5 后产品所有者复盘：全功能与 mini 两形态的差别只剩「拖动把手、按设置/原样文字、⋯菜单」，而文字存在的唯一理由是圆点主钮不可读——图标有了语义，文字就是冗余；折叠钮只为在两个几乎一样的形态间切换，浪费一格。另有两项使用诉求：胶囊拖动只能贴左右缘（#84 停靠模型）不够用；拖动把手常驻占一颗钮的位置。

## 决定

1. **单一胶囊形态**：把手 / 主按钮（面具图标）/ 媒体 / 遮住 / ⋯ 菜单，五段全图标钮；mini 形态、折叠钮、「按设置/原样」文字标签退场（`capsuleMini` 字段随整体写回自然消失）。⋯ 菜单常驻（原 mini 用户获得拖动与菜单）。
2. **主按钮 = 面具图标**（PageMask 本名隐喻）：按你的设置显示 = 戴面具（填实），原样 = 摘面具（描边）；眼睛挖孔用 evenodd 子路径，填实态读得出面具而不是色块。状态三路表达：填实/描边 + aria-pressed + title 全称，不只靠颜色。
3. **自由定位**：`ButtonPos` 退掉停靠边语义（x 表边、右停靠渲染 right），变为左上角视口绝对坐标——存什么渲染哪（夹进视口），窗口 resize 重夹。胶囊与幕布恢复按钮同模型。旧数据里的 x 本就是当时的左上角坐标，直接沿用。
4. **把手悬停显隐**：闲置整段透明但**保留占位**（宽度不变、其他钮不跳）；悬停胶囊 / 键盘聚焦 / 拖动中淡入；触屏（`pointer: coarse`）常显（无 hover 即不可发现）；`prefers-reduced-motion` 去过渡。

## Considered Options

- **保留双形态**（mini 加媒体钮已达成的现状）：否决——两形态差别只剩把手/文字/菜单，折叠钮纯为切换存在；双份测试与断言持续付税。
- **去掉把手、按住胶囊任意处拖动**：否决——每颗按钮都要背上「误拖 vs 点击」判别负担；六点把手悬停出现后是明确的「这个能拖」信号，误触为零。
- **主按钮换其他隐喻**（魔法棒/滤镜/对勾）：否决——面具与产品名互证、与眼睛/图片图标零冲突；滤镜类图形与「收起+标题图标」的多义职责不符。
- **旧停靠位迁移为贴边**：否决——自由定位下保留贴边特殊路径等于双模型并存；旧坐标本就是绝对坐标，直接沿用 + 夹紧即可，最多拖一下。

## Consequences

- 胶囊宽约 126px（五段全 24px 图标钮）：比 mini（99px）宽约 27px，比旧全功能（189px）窄 63px；闲置不透明度滑杆（10% 起）继续承担「低调」。
- 原右圆头（#85）从折叠钮移交 ⋯ 钮；文字标签的 4.5:1 对比度断言改为面具图标描边色。
- 挂载/删除/重置逻辑不再区分形态：`capsuleMini` 从 types/validate/applyKey 全链退场，popup「悬浮按钮」开关重置逻辑去形态分支。
- 把手闲置隐藏后，拖动的可发现性依赖悬停与键盘聚焦——E2E 断言 idle opacity=0、hover opacity=1 锁住该行为；键盘路径（Tab 聚焦把手 → 方向键）不变。
- 屏幕阅读器：主按钮 aria-pressed + title 全称不变；「按设置/原样」文字仅在弹窗与站点设置页出现。
