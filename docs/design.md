# PageMask 设计共识

本文档是 PageMask 的最终设计共识，是后续开发、建仓的唯一依据。术语定义见 [GLOSSARY.md](../GLOSSARY.md)，关键决策的背景与理由见 [docs/adr/](./adr/)。

- **项目名**：PageMask（界面显示「PageMask · 收起网页上不想看的部分」）
- **一句话定位**：点选网页上让你分心的元素，一键收起；标签页标题与图标也能一起变低调；有人走近时一键把整页遮住
- **技术栈**：WXT + Vue 3 + TypeScript，Chrome Manifest V3，成熟组件优先
- **分发路径**：先自用（开发者模式加载）→ GitHub 开源 → Chrome Web Store 上架

## 核心原则（优先级从高到低，冲突时靠上者赢）

1. **零影响**：用户不主动添加网站，插件对未添加的网站零影响——无注入、无界面、无性能开销。
2. **零专业知识**：主流程 0 正则、0 通配符、0 CSS；一切专业写法折叠隐藏在「高级」后门里。
3. **反向操作完备**：能添加就能修改/删除/清空/导出；不做只进不出的设计。

## 数据模型

```
站点配置（按域名，一个网站一份）
├── 开关状态：清爽态 / 原样态（界面：清爽 / 原样）
│     · 管「收起的内容 + 标签页标题和图标」这组定制；灰度独立于两态（见下，0.8.3 / ADR-0014）
│     · 按站点记忆（关闭时是清爽态→重开仍清爽态；否则原样态）
│     · 同一网站所有打开的标签页联动切换
├── 标签页标题（内部旧称"伪装标题"）：默认按浏览器界面语言取「阅读」/ "Reading"（不能设空白——空白时 Chrome 会在标签页上显示网址）
│     · 全局默认值可改（插件设置页），每站点可覆盖；快捷标题一键填入（新建标签页 / 阅读 / 文档 / 笔记，填入值随界面语言中英切换）
│     · **只有保存过「标题和图标」的网站才改标签页**（#98）：只收起内容的网站保持网站原来的标题与图标。
│       全局默认值因此只剩两处用途——打开该表单时的预填值、遮住整页时的标题
├── 标签页图标（#121）：三项选一——网站原来的图标（完全不接管 `<link rel=icon>`）/ 不显示图标（1×1 全透明 PNG，图标位留空）/ 换成别的图标（10 个内置题材，只存编号）；同样只在保存过「标题和图标」后生效，幕布不受此限
├── 图片和视频变灰（mediaGray，0.8.0 取代 0.7.x 三开关）：一个布尔字段，显式 true 才落库
│     · 独立于两态（0.8.3，ADR-0014）：主开关管「收起的内容 + 标签页标题图标」这组定制，
│       灰度按自己的开关走，原样态下照常生效。按网站记，同站所有标签页联动
│     · 图片与视频（含封面帧）grayscale(1)：黑白但可读可点、零交互；≤32px 小图标与表情留原样
│     · 站点自动播放的视频暂停；用户点击视频区域后放行该视频（画面保持黑白）；声音完全不碰（ADR-0013）
└── 收起规则 × N 条 —— 一条规则只收起一个东西，批量点选一次创建多条
      ① 藏什么：2-3 个候选选择器，由稳到险排序（语义属性 id/aria/data-* > 正常类名 > 结构路径），
         任一命中即算找到，全部失配才判失效
         · 生成时忽略 CSS-in-JS 机器乱码类名（css-、sc-、emotion- 等，React 站点重灾区）
         · 采用成熟库 css-selector-generator（天然输出候选序列）
         · 命中的同类元素默认一起藏；选内容清单的行内一道勾选框「页面上另外 N 个一样的也一起收起」可以取消
           （界面上不出现「同类」二字；勾上当场把这一组亮出来，一次一组——整组一条描边样式规则，
           小组与大组同一形态，不为成员逐个建 DOM；点带标记的组员 = 取消那条规则）
         · 元素自动命名：无障碍标签 > 元素文本前几字 > 位置描述（如"顶部导航栏"）
      ② 怎么收起：收起方式 A/B/C（见下节），每条规则各选一种
      ③ 在哪些页面收起：生效范围——整站（默认）/ 仅某类页面 / 排除某类页面
         · 零输入按钮生成（插件从当前网址自动推导"这类页面"），人话展示 + 网址示例
         · 失效体检只在该规则范围内的页面上进行
```

- 两条规则范围重叠且作用于同一元素：后创建的生效（v1 不做冲突检测界面）。
- 原样态 = 这组定制还原（收起的内容、标签页标题和图标；0.8.3 起灰度独立于两态，不受它管，ADR-0014）。

- **幕布不是配置**：遮住整页是页面内的临时状态，不写进站点配置、不影响开关状态；详见「幕布」一节。
- 「0 条收起设置、只改标题」的站点配置是合法形态：只想换标签页标题的网站也走站点配置，不需要收起任何元素。

## 收起方案

| 方案 | 界面用词 | 效果 | 风险 | 定位 |
|---|---|---|---|---|
| A 彻底移除 | 消失 | 元素消失，下方内容上移补位 | 布局重排可能变怪 | 首选 |
| B 原地留白 | 留空 | 元素全透明+不可点，位置保留，结构不动 | 极少站点自己控制可见性 | A 不满意时 |
| C 遮罩覆盖 | 盖住 | 不碰网站任何样式，原位盖一块与背景同色的贴纸 | 滚动时贴纸要跟手 | 站点的样式压不动时 |

三种方式都在预览清单的每一行直接可选（见「核心流程」第 3 步），不再有「保底方案藏在后面」的分层。选中某一项时，行下方显示一句白话解释当前效果。

## 核心流程（两条独立流程，#81）

没有「第一次设置」的特殊模式：不管有没有配置都是同一套编辑流程，有配置就以配置为起点。弹窗对新老网站一律两颗按钮：「收起内容」（实心主按钮）与「标题和图标」（次按钮）。

1. **进入**：插件弹窗两颗按钮或小按钮「⋯」菜单两项（「标题和图标」在上，0.8.15 #148 与弹窗一致）。站点还没有配置时先请权限（popup 发消息、后台在用户手势同一回合里请求），保存时才写配置；取消即收回授权。不做右键菜单、不做快捷键。页面处于「按你的设置显示」时先临时还原全部规则再进入，退出后恢复；处于幕布态时先撤幕布。
2. **收起内容（两步）**：选内容 → 看效果。进入点选时现有规则已铺成草稿起点，已收起的项直接进选择集——与新选的统一编号、进同一份清单、点号跳行（#81：页面上只有号码牌一种标记，不再有「之前收起了」角标）。点已收起的项 = 从清单里去掉（等同行上的 ✕）；再点 = 按默认值当新的一项加回（默认收起方式、同类默认只收一个）——一个手势只许一个意思，没有「原地替换」。选大一点 / 选小一点对旧项照常可用。「页面上另外 N 个一样的也一起收起」的勾选框住在选内容清单的行内（#82，sameHits > 1 才出现）：勾上当场把这一组亮出来，**勾谁看谁，一次一组**——整组一条描边样式规则（小组与大组同一形态，#100；滚动新加载的元素自动带上，不为成员逐个建 DOM）；点别的已勾选的行，亮着的组跟着换（点带标记的组员 = 取消那条规则）；其他规则的组员不常驻标记。「在哪些页面收起」仍属看效果阶段的行属性，不进点选。
3. **看效果**：全部选中元素统一按 A 应用 → 被移除元素原位出现幽灵标记（带序号角标，仅预览期间存在）→ 清单每行默认只放一件事：`序号 名称 调整 ✕`，名称可就地改，摘要一行写「收起方式 · 范围」（勾了同类的行再报一次「连一样的共 N 个」，#82；展开时隐藏）；收起方式、范围、高级选择器都折进「调整」——同类勾选框不在看效果里（#82），看效果阶段也不再新增组标记（整组已真实收起，所见即答案；「消失」成员沿用幽灵标记机制）。点号码牌滚到对应行并高亮。界面提示"请滚动页面确认效果"。**在哪些页面收起只在每行的「调整」里设**——没有整批控件。
4. **标题和图标（单步）**：单步小表单（复用 TitleIconFields）——标题就地输入（所见即所得，留空用默认「阅读」/ "Reading"）、图标三选一（网站原来的 / 不显示 / 换成内置的）。主按钮「保存」：新网站保存即建站（0 条收起设置 + 清爽态，沿用 titleOnlyPatch 语义）；老网站保存即更新，开关状态保持不变。没有下一步，也没有「只改标题，完成」。
5. **保存即完成**：看效果点「保存」写入配置、撤预览，页面当场变清爽，向导结束——没有额外的完成页。站点还没有配置时自动进入清爽态；已有站点维持当前开关状态（防在家配置时突然变样）。
6. **高级后门**：在「看效果」每行的「调整」里（页面上不直接暴露），选择器文本可手动编辑，但**保存前必须现场命中至少一个元素**（uBlock 同款门槛），否则不允许保存。
7. **入口拦截**：chrome:// 内部页面、file:// 本地页面在添加名单时识别并提示"此类页面不支持"。

| 插件设置页 | 独立页面（`settings.html`，注册为 Chrome 的「扩展程序选项」且 `open_in_tab`）：界面语言（跟随浏览器 / 简体中文 / English）、默认标题（含现成的标题）、快捷键（当前实际绑定 + 「在 Chrome 里更改」，未绑定时给警告）、悬浮按钮的「不透明度」滑杆（10%–100%，#110：拖动即时预览、松手保存，≤30% 提示「调得太淡会不容易找到」）、导出/导入（导出文件含插件设置与版本号）、关于（版本号、仓库地址、反馈入口）；左上角返回「你添加的网站」 |
| 首次引导 | 安装后 3 步图文：把 PageMask 固定到工具栏 / 弹窗里能做的三件事（收起内容、标题和图标、遮住这一页含快捷键）/ 平时用悬浮按钮。第 2、3 步直接渲染真实的弹窗与胶囊组件（#103），不手画示意图——弹窗改版时欢迎页自动跟上 |

管理页与插件设置页是**两个独立页面**，不再是一个页面里的两个 tab；站点设置页有自己的地址（`#/sites/<域名>`），支持前进后退与深链。

以上所有界面的颜色、字号、按钮层级与排布，一律按 `docs/design-ui.md`（界面基础规范）执行；那份文档写明每条规则取自哪个成熟设计系统。

## 标签页标题与图标

- 清爽态：改写 `document.title` + 替换 favicon，并监听页面 head 变化后**自动改回**（SPA 翻页瞬间改标题时也会改回）。补写频率受控：网站连击改标题合并成一拍一次；图标只在确实不一致时才动；连续抢不过（网站用定时器死守）就彻底放手并留下一条可查记录，浏览器保持流畅（#49）。参考实现 Tabee（chrome-tab-modifier）。
- **只在「保存过」的网站上做**（#98）：在「标题和图标」里点过保存并成功的网站才有这个行为；只保存过收起内容的网站，标题与图标完全不动。判定存在站点配置的 `titleIconSet` 字段里（旧数据按「有标题」推导）。「保存过」之后想回到原样，走「恢复网站原来的标题和图标」这个明确动作，不靠清空输入框猜。
  - 「恢复网站原来的标题和图标」（#99）：标题清空、图标回到「网站原来的图标」、标记回到未设置；不动收起规则、开关状态、站点授权与按钮位置。入口两处：向导「标题和图标」表单底部、站点设置页的标题 / 图标卡片之后，同名同物。
- 原样态：完全还原。
- 默认值（#35）：标题按浏览器界面语言取「阅读」/ "Reading"，生效顺序 站点标题 > 插件设置页的默认标题 > 语言默认，永不为空白。图标按站点三选一（#121）：「网站原来的图标」不接管 `<link rel=icon>`，网站自己换图标也跟着换；「不显示图标」写 1×1 全透明 PNG（图片能正常加载，Chrome 照常显示它，即图标位留空；只有没有图标或加载失败才显示默认地球图标）；「换成别的图标」写内置的 32×32 PNG data URL（10 个题材，产物在 `core/icon-presets.ts`）。没有「默认图标」这一层。默认值不模仿浏览器自己的界面（不用「新建标签页」作默认、不用 Chrome 图标），「新建标签页」/ "New Tab" 只作为快捷标题由用户自选。0.1.0 存下的全局标题若恰为旧默认「新建标签页」（无版本标记），视为未设置。
- 全局默认标题（#98 起）只在两处使用：打开「标题和图标」时的预填值；遮住整页时没单独设过标题的网站。它不再自动套到没保存过标题的网站。
- 商店卖点素材：同类产品最大抱怨是"重开浏览器就忘"，本插件按站点持久化天然解决。

## 幕布

有人走近时的应急反应：一键把整个页面连同标签页标题、图标一起遮住，人走之后再一键恢复成点之前的样子——不管点之前是清爽态还是原样态。

- **不写配置**：幕布是页面内的临时状态，不进站点配置、不改开关状态、不参与导入导出。只作用于当前标签页，同站其他标签页不受影响。待授权的站点（有配置、权限被收回）也能遮住，且用该站自己设置的标题。
- **入口与形态**：弹窗上的「遮住这一页 / 恢复这一页」开关（能来回点，遮住后重开弹窗按钮自己写着「恢复这一页」），小按钮上的「遮住」，或键盘快捷键（默认 `Ctrl+Shift+X`，Mac 上 `⌘+Shift+X`；同一个键切换遮住 / 恢复）。三处入口作用于**每个文档唯一的一个页面级控制器**（#107、ADR-0011）：任何一处遮住，另外两处都能恢复；没添加过的网站经一次性脚本走同一个控制器，可反复遮 / 撤。快捷键算一次用户手势，没添加过的网站也能遮；改键在 `chrome://extensions/shortcuts`，界面上显示实际绑定。遮住后页面上只剩一颗**睁眼图标的小按钮**（见「遮住按钮」词条）：与悬浮按钮同一套材质、可拖动、记住位置（已添加站点写回该站按钮坐标，一次性脚本写回一份全局位置）；常态 85% 不透明、只显示图标，悬停或键盘聚焦升到全不透明并显出「恢复」两个字。恢复即回到点击前的状态（ADR-0008）。
- **内容与颜色**：幕布本体不放任何文字、logo——旧共识「不放任何图标」已推翻：纯色幕布上没有任何入口时用户找不到怎么回来，所以保留一颗图标按钮，但常态不显示文字、颜色低调。颜色取页面自己的画布底色（`html`/`body` 上第一个不透明的背景色），取不到时浅色页面用白、深色页面用近黑——固定白屏在深色页面上会一眼暴露"这不是这个页面"。
- **标题与图标**：标题走和清爽态同一套（站点标题 > 全局默认 > 界面语言默认）；图标**固定全透明**（#121）——不管站点选的是「网站原来的图标」还是某个内置图标，遮住时都不能露出真图标。
- **恢复必须按进入前的状态分支**：进入前是清爽态就还原成清爽标题，是原样态就还原成真实标题与图标。不能一律"还原成真实"，那样清爽态会当场露馅。
- **生命周期**：刷新、整页跳转、关闭标签页后幕布消失（临时语义，不做跨刷新保持）；SPA 站内切换不受影响；进向导、删除这个网站的设置、扩展失效收尾前先撤幕布；幕布期间其他标签页或 popup 改开关，幕布保持在最上层并重新压住标题。
- **声音（0.8.0）**：遮住即静音当前标签页，恢复即还原；只解除本扩展设的那份（`mutedInfo.reason === 'extension'` 且本扩展），用户手动静音不碰；未添加网站的一次性幕布同样遮声。
- **未添加过的网站**：页面里没有内容脚本，只能从弹窗点「遮住这一页」，靠 `activeTab` 临时注入一份轻量脚本。代价是两次点击、且刷新即恢复；不进站点名单、不留任何配置。

**已知边界**（与实现质量无关，属平台限制）：视频全屏、页面内的 `<dialog>` / popover 渲染在浏览器 top layer 之上，会盖住幕布；标签页悬停缩略图与浏览历史里的标题仍是真实标题；幕布只挡眼睛不挡输入，键盘焦点仍在页面里，继续打字仍会改变页面内容；页面脚本可以直接删掉插件宿主。

## 失效体检

- 时机：只在**清爽态**下采集与展示（原样态不体检——规则本就不应用，只会假警报）。
- 方式：打开页面时核对每条规则（限其生效范围内的页面）的候选选择器是否命中。
- 表达：人话（"'顶部导航栏'最近找不到目标，可能网站改版了"）+「重新选一次」按钮跳编辑。
- 明示局限：存在性体检 ≠ 视觉体检——元素命中但被网站挪了位置时检测不出，靠人眼复核。

## 实现铁律

- **注入通道**：隐藏一律走 `chrome.scripting.insertCSS`（浏览器用户样式表通道 + `!important`）。禁止改行内样式（会被框架重渲染洗掉）、禁止插入 `<style>` 标签（会被严格 CSP 站点拦截）。注入记录按文档由内容脚本持有，后台无状态；内容脚本 `document_start` 启动，首屏用可构造样式表做几十毫秒的过渡遮挡（ADR-0005）。
- **性能**：方案 A/B 零监听（纯样式表）；MutationObserver 仅用于标题/图标补刀、遮罩滚动跟随、SPA 路由变化时重评估范围，以及**媒体变灰打开期间**的小图判定与视频播放压制（关掉即断开，未开启的页面零开销）。未配置站点零注入（按站点授权的 optional host permissions + 动态注册）。
- **媒体与声音（0.8.0，ADR-0013）**：灰度样式与隐藏规则走同一份用户样式表文本（`img:not([data-pm-media-keep]), video { filter: grayscale(1) }`）；小图豁免与视频自动播放压制是内容脚本的 JS 行为——压制 = 拦 `play` 并暂停，最近一次点击/按键落在视频区域则放行该视频；**不写任何 `muted`、不碰 `<audio>`**。幕布静音走 `chrome.tabs.update({ muted })`（不需要 `tabs` 权限），解除前核对 `mutedInfo.reason === 'extension' && extensionId === 本扩展`；还原由内容脚本 `pagehide` 触发、`tabs.onUpdated`（status loading）兜底。
- **存储**：`chrome.storage.local`；不用 `storage.sync`（公司/自购电脑互不串扰）。导出 JSON 带版本号字段供未来迁移，0.4.0 起还包含插件设置（默认标题），文件名 `pagemask-<版本>-<本地时间到秒>.json`。
- **权限**：最小权限集（storage、scripting、activeTab + 按站点可选主机权限），利于商店审核。manifest 不含 `content_scripts` / `host_permissions`，安装时没有任何站点权限提示。新增网站时的 `permissions.request` 一律由 popup 发消息、**后台在 `onMessage` 监听器里第一句直接调用**（用户手势可以跨 `runtime.sendMessage` 传到后台，但只在同一个同步回合内有效，之前不能有任何 `await`），请求返回后由后台继续对账、注入、开向导。
- **popup 是会死的上下文**：权限框、文件选择框都会销毁 popup。凡是"点了之后还要继续干活"的流程，都不能写在 popup 的 `await` 之后；文件导入导出这类能力不能放进 popup。
- **站点生命周期**：站点配置、站点授权、动态注册三者由后台幂等对账保持一致（安装/更新、浏览器启动、授权增减、配置增删、导入后）。有配置没授权的站点不删配置，显示「需要允许访问」：弹窗给「允许访问」，管理页给「允许访问」/「全部允许」。新站点首次设置保存时才写配置，取消即收回授权。「删除这个网站的设置」先让已打开页面还原，再收回授权、删配置。
- **遮罩方案 C**：滚动/缩放时贴纸跟随元素（rAF）；z-index 冲突时允许用户感知并换方案。

## 已知边界（明示不解决）

- 标签页悬停缩略图预览、浏览器历史记录里的真实标题：浏览器自身行为，无法改变。
- iframe 内、shadow DOM 内的元素第一版选择不了（检测到时给出提示）。
- **图片视频变灰是「看起来变灰」，不是不加载**：请求照发，开发者工具 Network 面板里还在；背景图、iframe 内嵌播放器、`<canvas>`、内联 SVG 不变灰；`<audio>` 与一切声音不参与；「点击放行」按最近一次点击/按键位置判定，真机在微博 / X 上验证。
- **幕布静音随幕布生灭**：刷新、离开页面、关标签页声音即还原；用户手动静音的标签页幕布不碰；Chrome 标签页上的斜线小喇叭只在「静音且最近出过声」时显示（Chrome 统一行为）。
- 手机/iPad 的 Chrome 不支持扩展，天然不存在跨设备问题。
- GitHub 不作为任何配置分发通道（Dark Reader 教训）。

## 版本切分

- **V1（全部，已随 0.1.0–0.5.0 实现）**：上文全部功能，含首次引导、导出/导入（导出文件含插件设置与版本号，默认合并，可选整体替换）、幕布（含未添加站点的一次性注入、可拖动的恢复按钮）、管理页拆分（网站列表 / 站点设置 / 插件设置三个页面）、全界面中英双语与界面语言设置、两条独立流程（#81：收起内容两步 + 标题和图标单步，无首次模式）。
- **0.7.0（#116）**：按站点的收起图片 / 收起视频 / 静音网页三个开关，三处入口、灰块保布局、视频停播、标签页静音；不做全局总开关，也不改变「永不做」清单。
- **0.8.0（#131）**：媒体三开关重做——「图片和视频变灰」（灰度降调、自动播放压制、点击放行）取代收起图片 / 收起视频；「静音网页」退场，静音并入幕布（遮住即静音、恢复即还原）；胶囊两种形态加「媒体」钮（ADR-0013 取代 ADR-0012）。
- **0.8.3（ADR-0014）**：灰度独立于主开关——主按钮只管「收起的内容 + 标签页标题和图标」，灰度按自己的开关在两种状态下都生效；胶囊媒体钮挪到遮住前，媒体钮开启态改「内容填实、外框描边」。
- **0.8.5（#134）**：没配置过的网站在弹窗里直接开灰度——打开时申请权限，后台补一份只带灰度的配置（switchState 保持原样态），内容脚本休眠唤醒生效；gray-only 站点的主按钮暂无可视效果（已知形态）。
- **0.8.6（#135）**：胶囊单一形态（ADR-0015）——主按钮改面具图标（去掉文字标签），mini/折叠退场；位置自由定位（不再贴边停靠）；把手悬停显隐（触屏常显）。
- **0.8.7（#135 修复票）**：灰-only 站点关灰度不再拆胶囊——挂载判据只在页面加载时评估，会话内配置变空不拆已挂着的按钮（ADR-0014「日后再议」收口）。
- **0.8.8（#136）**：胶囊去把手（ADR-0016）——整根胶囊表面都能拖（移动 ≥8px 算拖动、不足算点击），静止宽度 126→约 101px；方向键移动挂到本体；触屏主按钮补齐 40×40 档。形态调研结论：横排保留、横竖排切换不做（主流产品与设计系统查无先例）。
- **V2（视需要）**：幕布跨刷新保持（ADR-0007 候选）。
- **永不做**：除幕布快捷键以外的任何快捷键（ADR-0010：全产品只有这一条命令）、全局总开关、内置站点预置规则、远程配置订阅、右键菜单入口、uBlock 式免保存临时隐藏（指**元素级**的临时隐藏不落库——编辑半天忘了存；幕布是整页遮蔽，不涉及规则编辑，见 [ADR-0007](./adr/0007-curtain-ephemeral-full-page-cover.md)）。
