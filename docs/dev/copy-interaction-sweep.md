### 看过后不改（附理由）

- **全部网站设置·列表行**「按设置 · 还没有收起设置」：这是行内的收起项计数，不挂在开关上；列表要能一行扫完，换成完整配置摘要会让每行变长。弹窗 / 设置页的开关状态行已经修过（#11、#12）。
- **插件设置·快捷键未绑定**「没有绑定快捷键，可能被系统或其他扩展占用了」：紧挨着就是「到 Chrome 里设置快捷键」按钮，动作不重复塞进句子里。
- **导入文件过大**「文件超过 20 MB…」：文件选择器就在旁边，下一步显而易见。
- **向导·「这一组没法稳定找到，还保持你原来选的样子」**：结果已经说清（保持原选择），没有可执行动作；硬加「再试一次」会与自动回退冲突。
- **空状态**（收起的内容、网站列表、向导选中列表）：各自都有紧邻的编辑入口或引导句，不是孤零零一句。
