# PageMask 设计共识

本文档是 PageMask 的最终设计共识，是后续开发、建仓的唯一依据。术语定义见 [GLOSSARY.md](../GLOSSARY.md)，关键决策的背景与理由见 [docs/adr/](./adr/)。

- **项目名**：PageMask（界面显示「PageMask · 页面清爽模式」）
- **一句话定位**：点选网页上让你分心的元素，一键收起；标签页标题与图标也能一起变低调；有人走近时一键把整页遮住
- **技术栈**：WXT + Vue 3 + TypeScript，Chrome Manifest V3，成熟组件优先
- **分发路径**：先自用（开发者模式加载）→ GitHub 开源 → Chrome Web Store 上架

## 核心原则（优先级从高到低，冲突时靠上者赢）

1. **零影响**：用户不主动添加网站，插件对未添加的网站零影响——无注入、无界面、无性能开销。
2. **零专业知识**：主流程 0 正则、0 通配符、0 CSS；一切专业写法折叠隐藏在「高级」后门里。
3. **反向操作完备**：能添加就能修改/删除/清空/导出；不做只进不出的设计。

## 数据模型

```
站点配置（按域名，一个网站一份）
├── 开关状态：清爽态 / 原样态（界面：清爽 / 原样）
│     · 按站点记忆（关闭时是清爽态→重开仍清爽态；否则原样态）
│     · 同一网站所有打开的标签页联动切换
├── 标签页标题（内部旧称"伪装标题"）：默认按浏览器界面语言取「阅读」/ "Reading"（不能设空白——空白时 Chrome 会在标签页上显示网址）
│     · 全局默认值可改（插件设置页），每站点可覆盖；快捷标题一键填入（新建标签页 / 阅读 / 文档 / 笔记，填入值随界面语言中英切换）
├── 标签页图标（内部旧称"伪装图标"）：三层生效顺序——站点自己设的 > 插件设置页的默认图标 > 1×1 全透明图标（标签页上图标位显示为空白）；站点与插件默认都没设时才是透明
└── 收起规则 × N 条 —— 一条规则只收起一个东西，批量点选一次创建多条
      ① 藏什么：2-3 个候选选择器，由稳到险排序（语义属性 id/aria/data-* > 正常类名 > 结构路径），
         任一命中即算找到，全部失配才判失效
         · 生成时忽略 CSS-in-JS 机器乱码类名（css-、sc-、emotion- 等，React 站点重灾区）
         · 采用成熟库 css-selector-generator（天然输出候选序列）
         · 命中的同类元素一起藏，预览中可切换「只藏这个 / 一起藏」
         · 元素自动命名：无障碍标签 > 元素文本前几字 > 位置描述（如"顶部导航栏"）
      ② 怎么收起：收起方式 A/B/C（见下节），每条规则各选一种
      ③ 在哪些页面收起：生效范围——整站（默认）/ 仅某类页面 / 排除某类页面
         · 零输入按钮生成（插件从当前网址自动推导"这类页面"），人话展示 + 网址示例
         · 失效体检只在该规则范围内的页面上进行
```

- 两条规则范围重叠且作用于同一元素：后创建的生效（v1 不做冲突检测界面）。
- 原样态 = 完全还原（标题、图标一并还原）。
- **幕布不是配置**：遮住整页是页面内的临时状态，不写进站点配置、不影响开关状态；详见「幕布」一节。
- 「0 条规则、只改标题」的站点配置是合法形态：只想换标签页标题的网站也走站点配置，不需要收起任何元素。

## 收起方案

| 方案 | 界面用词 | 效果 | 风险 | 定位 |
|---|---|---|---|---|
| A 彻底移除 | 消失 | 元素消失，下方内容上移补位 | 布局重排可能变怪 | 首选 |
| B 原地留白 | 留空 | 元素全透明+不可点，位置保留，结构不动 | 极少站点自己控制可见性 | A 不满意时 |
| C 遮罩覆盖 | 盖住 | 不碰网站任何样式，原位盖一块与背景同色的贴纸 | 滚动时贴纸要跟手 | 站点的样式压不动时 |

三种方式都在预览清单的每一行直接可选（见「核心流程」第 3 步），不再有「保底方案藏在后面」的分层。选中某一项时，行下方显示一句白话解释当前效果。

## 核心流程（设置向导，三步）

1. **进入**：插件弹窗点「为当前网站开启清爽模式」（新站点，授权后直接进向导）或「＋ 收起更多内容」（已有站点）。不做右键菜单、不做快捷键。页面处于清爽态时先临时还原全部规则再进入，退出后恢复；处于幕布态时先撤幕布。
2. **第 1 步 · 标签页标题和图标**：向导开场先把标签页收拾好——标题就地输入（所见即所得，留空用默认「阅读」/ "Reading"）、图标可上传；三层顺序见「标签页标题与图标」。只改标题、不收起任何内容是合法出口：第 1 步填完点「只改标题，完成」即可保存走人。
3. **第 2 步 · 点选要收起的内容**：悬停高亮（轮廓+简要说明）→ 点击选中、再点取消 → 连续多选 → 已选内容列成清单（可逐项删掉、「全部删掉」一次清空）→ 「选大一点 / 选小一点」调整层级（解决点选中内层文字的痛点）→ 防呆：选到整页大小元素时提示。
4. **第 3 步 · 看效果**：全部选中元素统一按 A 应用 → 被移除元素原位出现幽灵标记（带序号角标，仅预览期间存在）→ 清单每行就是一个完整的编辑单元：`序号 名称 [消失][留空][盖住] ✕`，名称可就地改；「只这一个 / 同类一起（N）」切换（数字实时计算）。点号码牌滚到对应行并高亮。界面提示"请滚动页面确认效果"（遮罩方案的问题只在滚动时暴露）。**生效范围整批设一次**（整站 / 只在这类页面 / 除了这类页面，默认整站，零输入），就放在这一步。
5. **保存即完成**：第 3 步点「保存」写入配置、撤预览，页面当场变清爽，向导结束——没有额外的完成页。新站点自动进入清爽态；已有站点维持当前开关状态（防在家配置时突然变样）。
6. **高级后门**：在页面内编辑面板里（不在向导），选择器文本可手动编辑，但**保存前必须现场命中至少一个元素**（uBlock 同款门槛），否则不允许保存。
7. **入口拦截**：chrome:// 内部页面、file:// 本地页面在添加名单时识别并提示"此类页面不支持"。

| 管理页 · 你添加的网站 | 独立页面（`management.html#/sites`）：已添加网站的列表，一行一站：图标、域名、清爽/原样、已收起项数、可能失效提示；待授权站点在这一行给出「授权并启用」（多个时可一次授权全部）。点某一行进入该站的站点设置页 |
| 管理页 · 站点设置 | 独立页面（`management.html#/sites/<域名>`）：单个网站的全部设置，四个区块与小胶囊「⋯」菜单同一批名字——标签页标题（含快捷填入）、标签页图标（上传/清除）、收起的内容（可删除，5 秒内可撤销；换方式与重选元素给「在页面上编辑」跳到页面内）、删除这个网站的设置（红字，二次确认，列明影响）。标签页标题和图标的就地编辑入口在页面上，不在这里 |

| 首次引导 | 安装后 4 步图文（含「把 PageMask 固定到工具栏」）：现在的面板（两个底部入口、遮住开关）与三步向导 |

管理页与插件设置页是**两个独立页面**，不再是一个页面里的两个 tab；站点设置页有自己的地址（`#/sites/<域名>`），支持前进后退与深链。

## 标签页标题与图标

- 清爽态：改写 `document.title` + 替换 favicon，并监听页面 head 变化后**自动改回**（SPA 翻页瞬间改标题时也会改回）。补写频率受控：网站连击改标题合并成一拍一次；图标只在确实不一致时才动；连续抢不过（网站用定时器死守）就彻底放手并留下一条可查记录，浏览器保持流畅（#49）。参考实现 Tabee（chrome-tab-modifier）。
- 原样态：完全还原。
- 默认值（#35）：标题按浏览器界面语言取「阅读」/ "Reading"，生效顺序 站点标题 > 插件设置页的默认标题 > 语言默认，永不为空白。图标三层：站点自己设的 > 插件设置页的默认图标 > 1×1 全透明 PNG（图片能正常加载，Chrome 照常显示它，即图标位留空；只有三层都没有或加载失败才显示默认地球图标）。默认值不模仿浏览器自己的界面（不用「新建标签页」作默认、不用 Chrome 图标），「新建标签页」/ "New Tab" 只作为快捷标题由用户自选。0.1.0 存下的全局标题若恰为旧默认「新建标签页」（无版本标记），视为未设置。
- 商店卖点素材：同类产品最大抱怨是"重开浏览器就忘"，本插件按站点持久化天然解决。

## 幕布

有人走近时的应急反应：一键把整个页面连同标签页标题、图标一起遮住，人走之后再一键恢复成点之前的样子——不管点之前是清爽态还是原样态。

- **不写配置**：幕布是页面内的临时状态，不进站点配置、不改开关状态、不参与导入导出。只作用于当前标签页，同站其他标签页不受影响。待授权的站点（有配置、权限被收回）也能遮住，且用该站自己设置的标题。
- **入口与形态**：面板上的「遮住本页 / 恢复本页」开关（能来回点，遮住后重开面板按钮自己写着「恢复本页」），或小胶囊上的「遮住」。遮住后页面上只剩一颗**睁眼图标的小按钮**（见「遮住按钮」词条）：与小胶囊同一套材质、可拖动、记住位置（已添加站点写回该站胶囊坐标，一次性脚本写回一份全局位置）；常态 85% 不透明、只显示图标，悬停或键盘聚焦升到全不透明并显出「恢复」两个字。恢复即回到点击前的状态（ADR-0008）。
- **内容与颜色**：幕布本体不放任何文字、logo——旧共识「不放任何图标」已推翻：纯色幕布上没有任何入口时用户找不到怎么回来，所以保留一颗图标按钮，但常态不显示文字、颜色低调。颜色取页面自己的画布底色（`html`/`body` 上第一个不透明的背景色），取不到时浅色页面用白、深色页面用近黑——固定白屏在深色页面上会一眼暴露"这不是这个页面"。
- **标题与图标**：走和清爽态同一套（站点标题 > 全局默认 > 界面语言默认；透明图标）。
- **恢复必须按进入前的状态分支**：进入前是清爽态就还原成清爽标题，是原样态就还原成真实标题与图标。不能一律"还原成真实"，那样清爽态会当场露馅。
- **生命周期**：刷新、整页跳转、关闭标签页后幕布消失（临时语义，不做跨刷新保持）；SPA 站内切换不受影响；进向导、删除这个网站的设置、扩展失效收尾前先撤幕布；幕布期间其他标签页或 popup 改开关，幕布保持在最上层并重新压住标题。
- **未添加过的网站**：页面里没有内容脚本，只能从 popup 点「遮住本页」，靠 `activeTab` 临时注入一份轻量脚本。代价是两次点击、且刷新即恢复；不进站点名单、不留任何配置。

**已知边界**（与实现质量无关，属平台限制）：视频全屏、页面内的 `<dialog>` / popover 渲染在浏览器 top layer 之上，会盖住幕布；标签页悬停缩略图与浏览历史里的标题仍是真实标题；幕布只挡眼睛不挡输入，键盘焦点仍在页面里，继续打字仍会改变页面内容；页面脚本可以直接删掉插件宿主。

## 失效体检

- 时机：只在**清爽态**下采集与展示（原样态不体检——规则本就不应用，只会假警报）。
- 方式：打开页面时核对每条规则（限其生效范围内的页面）的候选选择器是否命中。
- 表达：人话（"'顶部导航栏'的隐藏规则最近在阅读类页面没找到目标，可能网站改版了"）+「去处理」按钮跳编辑。
- 明示局限：存在性体检 ≠ 视觉体检——元素命中但被网站挪了位置时检测不出，靠人眼复核。

## 实现铁律

- **注入通道**：隐藏一律走 `chrome.scripting.insertCSS`（浏览器用户样式表通道 + `!important`）。禁止改行内样式（会被框架重渲染洗掉）、禁止插入 `<style>` 标签（会被严格 CSP 站点拦截）。注入记录按文档由内容脚本持有，后台无状态；内容脚本 `document_start` 启动，首屏用可构造样式表做几十毫秒的过渡遮挡（ADR-0005）。
- **性能**：方案 A/B 零监听（纯样式表）；MutationObserver 仅用于标题/图标补刀、遮罩滚动跟随、SPA 路由变化时重评估范围。未配置站点零注入（按站点授权的 optional host permissions + 动态注册）。
- **存储**：`chrome.storage.local`；不用 `storage.sync`（公司/自购电脑互不串扰）。导出 JSON 带版本号字段供未来迁移，0.4.0 起还包含插件设置（默认标题、默认图标），文件名 `pagemask-<版本>-<本地时间到秒>.json`。
- **权限**：最小权限集（storage、scripting、activeTab + 按站点可选主机权限），利于商店审核。manifest 不含 `content_scripts` / `host_permissions`，安装时没有任何站点权限提示。新增网站时的 `permissions.request` 一律由 popup 发消息、**后台在 `onMessage` 监听器里第一句直接调用**（用户手势可以跨 `runtime.sendMessage` 传到后台，但只在同一个同步回合内有效，之前不能有任何 `await`），请求返回后由后台继续对账、注入、开向导。
- **popup 是会死的上下文**：权限框、文件选择框都会销毁 popup。凡是"点了之后还要继续干活"的流程，都不能写在 popup 的 `await` 之后；文件相关的能力（图标上传）不能放进 popup。
- **站点生命周期**：站点配置、站点授权、动态注册三者由后台幂等对账保持一致（安装/更新、浏览器启动、授权增减、配置增删、导入后）。有配置没授权的站点不删配置，显示「待授权」：popup「重新授权」，管理页「授权并启用」/「一次授权全部」。新站点首次向导保存时才写配置，取消即收回授权。「删除这个网站的设置」先让已打开页面还原，再收回授权、删配置。
- **遮罩方案 C**：滚动/缩放时贴纸跟随元素（rAF）；z-index 冲突时允许用户感知并换方案。

## 已知边界（明示不解决）

- 标签页悬停缩略图预览、浏览器历史记录里的真实标题：浏览器自身行为，无法改变。
- iframe 内、shadow DOM 内的元素第一版选择不了（检测到时给出提示）。
- 手机/iPad 的 Chrome 不支持扩展，天然不存在跨设备问题。
- GitHub 不作为任何配置分发通道（Dark Reader 教训）。

## 版本切分

- **V1（全部，已随 0.1.0–0.4.0 实现）**：上文全部功能，含首次引导、导出/导入（导出文件含插件设置与版本号，默认合并，可选整体替换）、幕布（含未添加站点的一次性注入、可拖动的恢复按钮）、管理页拆分（网站列表 / 站点设置 / 插件设置三个页面）、全界面中英双语与界面语言设置、三步向导。
- **V2（视需要）**：办公软件风格图标预制包（邮件/文档/表格）；幕布跨刷新保持（ADR-0007 候选）。
- **永不做**：键盘快捷键（两次明确否决）、全局总开关、内置站点预置规则、远程配置订阅、右键菜单入口、uBlock 式免保存临时隐藏（指**元素级**的临时隐藏不落库——编辑半天忘了存；幕布是整页遮蔽，不涉及规则编辑，见 [ADR-0007](./adr/0007-curtain-ephemeral-full-page-cover.md)）。
