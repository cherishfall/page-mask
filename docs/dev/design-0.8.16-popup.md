## 二、#152 胶囊开启态（推翻 0.8.15 §五的「三信号」方案）

- **推翻记录**：0.8.15 的「强调色图标 + 分段底部 2px 指示条」有两个真实问题——① 指示条紧贴胶囊 1px 边框，读成两道重复的线（HANDOFF §2 早已登记沿圆头被裁 7px、两颗可见长度不一）；② 用户不喜欢开启变蓝。
- **对照**（AGENTS.md 要求 ≥3 来源）：M3 icon button toggleable（选中 = filled icon + secondaryContainer 淡色容器，不用 primary）、Carbon 工具栏图标选中态（layer-selected 淡灰底）、iOS 控制中心（激活 = 色调底 + 填实图标）。三家一致：**图标开关的选中态不用强调色、不用指示条**。
- **落地**：图标 `--pm-fg-muted → --pm-fg`（墨色浓淡）+ 图标填实 vs 描边（形状）双信号承载状态（WCAG 1.4.1 / 1.4.11），`--pm-bg-selected`（浅 `#dde1e6` / 深 `#303743`，fg 对其 12.01:1 / 9.67:1）选中底为辅助信号；悬停 / 按下用 M3 state layer 薄层（`--pm-state-hover` / `--pm-state-press`，box-shadow inset 9999px 全覆盖画法，不改布局盒）；`forced-colors` 走系统 Highlight。眼缝挖孔随选中底。弹窗卡头同源图标同步墨色（同源同态）。
- 状态语义不变：填实 = 按你的设置显示 / 灰度开，描边 = 原样 / 灰度关。

## 三、#153 弹窗观感（部分推翻 0.8.15 §三/§四的取舍）

- **推翻记录**：① 「主按钮实心蓝」退位——用户明确推翻；② 辅助行上方分割线删除；③ 密度 8→4 的「中文为英文买单」反向——以砍短的文案换回 8px 组件间距 / 12px 卡片内边距。
- **结构不变**：四块（面具卡 / 灰度卡 / 遮住卡 / 辅助行）与胶囊四段的对应关系、new/ready 同构、两颗编辑入口并排等高 40px、「查看使用说明」在头部——全部保留。
- **文字砍短**（中英同写）：ready 态卡头说明行删除；灰度卡「单独记，不受上面的开关影响。」；遮住卡「临时遮住，刷新就还原，不改设置。」；悬浮按钮行「关掉后，页面上不再显示悬浮按钮。」；new 态灰度卡「打开时浏览器会先让你允许访问这个网站。」、卡头「设置好之后，这里会出现开关。」。
- **ⓘ 信息标**（用户提的形态）：灰度卡（黑白可读可点 / 自动播放暂停 / 点击放行）与悬浮按钮行（弹窗设置与快捷键照常可用）各一枚；悬停或键盘聚焦浮出（可聚焦 span + `:focus-within`）、Esc 撤下（WCAG 1.4.13）；浮层 `inset-inline: 0` 锚定整行宽度——按图标居中 / 右对齐都会被弹窗窗口裁切。
- **底部入口改文字链接**：muted + 下划线（GOV.UK 链接惯例解决 #74「无框小字看着像不能点」的顾虑）、hover 变正文色、命中区 ≥24；删除入口上方保留一条分隔线（危险动作与导航分开）。
- **按钮层级**：两颗编辑入口同为次操作档；pending 态「允许访问」仍是实心主按钮（那一屏唯一的动作）。
- 高度红线继续由 `check-language.mjs` 守门（英文 ready ≤600px）。

## 四、#154 灰度两根因（详见 ADR-0017 与 background-engine 注释）

- **多抓鱼**：书封 / 店铺头像走 CSS background-image（首页 2 张 `<img>`、18 个背景图元素），`img/video` 选择器盖不住 → 内容脚本扫描打 `data-pm-media-bg`（≤32px / 表情 / 自家 UI 豁免），CSS 扩一段；增量扫描改子树全扫 + rAF 分批 + 600 元素阈值。真实站点复验：18/18 全灰。
- **推特**：代理抖动 → Chrome 网络错误页 → `executeScript` 抛 "Frame with ID 0 is showing error page" → 0.8.15 及之前配置没建成、灰度永远开不上 → initialMedia 流程注入失败但权限已到手时照常建档，回复新码 `pageNotReady`，弹窗给说明（「这个页面还没加载好。打开之后，图片和视频会自动变黑白。」）而非报错。
- **边界**：iframe 内嵌播放器 / canvas / 内联 SVG 仍不变灰；运行中改 class 换上背景图的元素可能漏标（刷新后生效）；filter 连带灰掉容器内文字——均已写进 design.md 已知边界与 GLOSSARY。
