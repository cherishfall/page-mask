# 安全策略 / Security Policy

[中文](#中文) · [English](#english)

## 中文

### 支持的版本

仅最新发布版本接收安全修复。

### 报告漏洞

请**不要**通过公开 issue 报告安全问题。可选渠道：

1. **GitHub 私密漏洞报告**（推荐）：在本仓库 [Security → Advisories](https://github.com/cherishfall/page-mask/security/advisories/new) 点击 "Report a vulnerability"。
2. **邮件**：cherishfall@hotmail.com（标题请注明 `[PageMask Security]`）。

请尽量附上：受影响的版本、复现步骤、影响范围，以及（如适用）可触发问题的导入文件或规则示例。

我们会在 7 天内确认收到，修复后在 CHANGELOG 中致谢（如你愿意）。

### 范围

特别关注：通过「导入」引入的规则或样式能否影响扩展页面本身、越权读取页面数据、或绕过按站点授权。

## English

### Supported versions

Only the latest released version receives security fixes.

### Reporting a vulnerability

Please **do not** report security issues through public issues. Use one of:

1. **GitHub private vulnerability reporting** (preferred): go to [Security → Advisories](https://github.com/cherishfall/page-mask/security/advisories/new) and click "Report a vulnerability".
2. **Email**: cherishfall@hotmail.com (please prefix the subject with `[PageMask Security]`).

Please include the affected version, reproduction steps, impact, and, if relevant, a sample import file or rule that triggers the issue.

We aim to acknowledge reports within 7 days and will credit you in the CHANGELOG after the fix if you wish.

### Scope

Of particular interest: whether rules or styles brought in via Import can affect the extension's own pages, read page data beyond what is needed, or bypass per-site permission grants.
