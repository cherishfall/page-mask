# 幕布：临时的整页遮蔽，不落库、不跨刷新

有人走近时，一键把整个页面连同标签页标题、图标遮住；再点一次回到点击前的状态。它解决的是「页面内容本身不能被人看到」，而收起规则解决的是「这个页面太吵」——两件事，不能共用一套数据。

幕布做成**页面内的临时状态**，不进 `SiteProfile`、不进导出文件、不改 `switchState`：

- 状态只活在内容脚本里，只作用于当前标签页。同站其他标签页不受影响，也不写 `storage`，因此没有第二个标签页要同步，也没有「上次忘了恢复」的残留。
- 刷新、整页跳转、关掉标签页即恢复。这是刻意的：幕布是「现在这几秒」的东西，不是一种页面模式。
- 恢复必须按进入前的状态分支：进入前是清爽态就还原成清爽标题与图标，是原样态就还原成真实标题与图标。一律调 `TitleFaviconGuard.restore()` 会把真实标题放出来，清爽态当场露馅。
- 遮住期间仍要压住标题：其他标签页、popup 改开关都会触发 `applyAll` / `restoreAll`，这两个函数会重新调 `guard`，所以幕布必须在这两条路径之后重新断言自己。
- 颜色取页面自己的画布底色，取不到才用浅色白 / 深色近黑兜底。固定白屏在深色页面上会一眼看出「这不是这个页面」，与「不让旁人注意」的目的相反。

未添加过的网站没有内容脚本（ADR-0001），只能从 popup 点「遮住本页」，用 `activeTab` 临时注入一份轻量脚本。这不违反「未配置零影响」：没有用户点击就没有任何注入。

## Considered Options

- **做成第三种开关状态（`disguised` / `original` / `curtain`）**：被否决。开关是按站点持久化并跨标签页联动的，幕布一旦落库就会变成「上次忘关，明天打开还是白屏」；而且它会让「原样态 = 完全还原」的语义出现第三种解释，导入导出、失效体检、popup 开关全要改。
- **复用元素级遮罩（方案 C）盖住 `html`**：被否决。`MaskLayer` 是「一个选择器命中几个元素就盖几块、每块跟随元素矩形」，`html` 的矩形是**整个文档高度**而不是视口，盒子会跟着文档滚走；`maskColorFor(html)` 的祖先链为空，只会拿到画布兜底色。共用宿主还带一个问题：清掉元素遮罩会把整页层一起清掉。
- **用 `:root { opacity: 0 }` 这类整页 CSS**：被否决。它会把插件自己的宿主一起隐藏，恢复入口随之消失；而且要么走 `insertCSS` 新增第四份样式记录、要么走 `adoptedStyleSheets`（作者层，会被页面 `!important` 压过）。DOM 覆盖层不碰样式体系。
- **跨刷新保持（`sessionStorage` + `document_start` 抢先遮挡）**：暂不做。代价是幕布要接进首屏遮挡那条路径，把「读到配置前先整页透明」和「上次遮着，这次继续遮」两件事缝在一起；收益是「老板让你刷新一下」这一种场景。留作 V2 候选。
- **快捷键触发**：不做。设计文档「永不做」清单里明确排除，两次否决过。

## Consequences

- 与「永不做：uBlock 式免保存临时隐藏」不冲突：那条讲的是**元素级**的临时隐藏不落库，副作用是配了半天忘了存；幕布是整页遮蔽，不涉及规则编辑，也没有「该存没存」的问题。
- 平台限制带来的边界，已写进设计文档「幕布」一节：视频全屏与页面内 `<dialog>` / popover 在 top layer 之上会盖住幕布；标签页悬停缩略图和浏览历史仍是真实标题；幕布只挡眼睛不挡输入，键盘焦点仍在页面里；页面脚本可以直接删掉插件宿主。
- 未添加站点那条路要新起一份轻量脚本与一条注入路径，`activeTab` 在不同 Chrome 版本上的授予时机需实测；它不影响已添加站点的实现。
