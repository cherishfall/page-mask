## 一、为什么要这张表

同一组功能项在三个界面各写一份顺序、各写一份文案，历史上反复漏改：

- **#80**：弹窗与胶囊菜单的「标题和图标 / 收起内容」顺序相反。
- **#148**：同步调换时在 commit 正文里明写「站点设置页区块是另一组结构，不在本票范围」，
  第三处被正式排除，分叉被写进流程。
- **#152**：派单清单漏一行，子代理少改一处。
- **#153**：只改弹窗，「收起内容」已是次操作档的结论没同步到文档。
- **#156（0.8.18）**：开关名从「图片和视频变灰」改成「整页变灰」，卡头 `t.media.heading`
  仍是 0.8.0 的「图片和视频」——站点设置页一张卡里，标题和开关成了两个名字。这是活的证据。

结论：顺序和叫法不能再靠三份模板 + 三份 E2E 各自硬编码来守。本文是唯一的对照口径，
自动检查从本文派生期望值。

## 二、规矩

1. **相对顺序必须一致。**「序」是全产品统一的相对顺序。每个界面按自己的形态跳过没有的项，
   但跳过后剩下的先后关系必须与「序」一致。**不要求三处长一样**：弹窗是快捷卡片、胶囊是
   最小工具栏、设置页是完整表单；弹窗把「标题和图标」「收起内容」并成同一张卡里的两颗按钮、
   设置页把它们拆成两张卡，都是合法形态。
2. **同一样东西只有一种叫法。** 每行的「界面用词」是该行在每个界面的登记名；模板不许写死文字，
   必须取「文案键」那一列（中英各一份）。新增叫法先改 `GLOSSARY.md`，再改这里。
   英文里卡片 / 分组名用名词短语、开关用动作短语，是刻意的角色区分；中文两处同名。
3. **控件来源同一份。** 弹窗与设置页的开关是 `role="switch"` 的 `input[switch]`，胶囊是
   `aria-pressed` 的图标钮——这是已登记的形态差异（`tests/media-ui.test.ts`），不是分叉；
   三处写入都只走 `mediaFlagPatch`，外观只走 `--pm-*` 与共享控件样式。
4. **表格是机器可读的。** 固定列、固定分隔符（`|`），`—` 表示该界面没有这一项；不要在表里
   加自由格式段落或合并单元格。解析器在 `tests/e2e/lib/surfaces.mjs`。

## 五、登记在案的两条例外

**例外① 胶囊的灰度钮在胶囊本体，不在 ⋯ 菜单。**
0.8.3 起的既有决策：灰度是随看随切的高频状态开关（ADR-0014），所以放在胶囊本体、紧挨主按钮；
遮住是应急动作，排在它后面（高频在前、应急最远）。菜单里不再重复这一项，4.3 表因此没有「整页变灰」行。
这是**形态差异**，不是分叉：三处仍是同一个开关、同一份存储、同一个叫法。

**例外② 胶囊主按钮在空设置时的说明形态。**
开关管不到任何东西时（收起的内容、标签页标题和图标都空；只有灰度不算，灰度独立于主开关），
三处都要说一句 `打开后页面不变`（`common.switchNoEffectHint`），判据只有一份：`core/site-state.ts`
的 `hasSwitchEffect`。弹窗与站点设置页把这句话当常驻 hint 放在开关下面；胶囊本体只有图标、
写不下文字，所以**点主按钮照常切换开关**，同时用一颗原生模态对话框
（`ui/toggle/EmptySettingsDialog.vue`，`data-testid="pm-tg-empty-dialog"`，与删除确认同款外壳）
显示同一句话 + 一个「知道了」，Esc / 回车 / 点框外都能关。

这是**形态差异**，不是分叉：三处同一句话、同一个判断，开关在三处都照常可拨、不禁用、不隐藏。
对话框只在点下去的那一刻出现、不占胶囊版面，也不进 4.2 表的常驻项，因此不占「序」；
**顺序与叫法本条不豁免**，往后改动仍以本表为准。不用页底轻提示：它是几秒就走的，
用户明确说过看不见。

## 六、自动检查覆盖什么

`tests/surfaces.test.ts`（提交前就跑）：

1. **顺序**：三份模板里每个控件的首次出现位置必须严格递增，顺序与 4.x 表一致。
2. **叫法**：每一行的文案键解析出的中英文，必须与表里的「界面用词」逐字相等。
3. **不写死**：三份模板的文本里不允许出现这些界面用词的字面值——必须走文案键。
4. **同义键同值**：`media.heading` / `media.mediaGray` / `media.mediaTitle` 的中文必须同名；
   `management.deleteSite.heading` / `toggle.menuDelete` 必须同名。
5. **E2E 不再各写一份**：三条 E2E 必须从 `tests/e2e/lib/surfaces.mjs` 取期望值，源码里不许再
   出现整串的菜单顺序 / 设置页五块标题。

E2E 侧额外做**渲染后**的顺序与叫法比对（弹窗 / 胶囊本体 / 菜单 / 设置页），防止模板解析通过、
真正渲染出来的顺序却被 CSS 或条件分支改掉。
