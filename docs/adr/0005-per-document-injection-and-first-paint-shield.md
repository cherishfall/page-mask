# 隐藏样式按文档跟踪 + 首屏过渡遮挡

隐藏样式（ADR-0002 的用户样式表）的注入记录属于**文档**，由该文档里的内容脚本持有，每次请求把「本文档当前已注入的文本」（prev）带给后台；后台不保存任何注入状态，用 `sender.documentId` 定位文档、用 `sender.url` 判断生效范围，按 prev → next 替换（相同跳过；不同先插新后删旧），并回传替换后文档里实际存在的文本。正式样式与向导预览样式各记一份，同一文档的请求在内容脚本里串行执行。

内容脚本改为 `document_start` 启动。由于正式样式要经后台往返一次，赶不上首帧，启动时先用**可构造样式表**（`new CSSStyleSheet()` + `document.adoptedStyleSheets`）把整页设为透明；读到配置后换成该页的精确隐藏规则（与正式样式同一份 css-builder 输出），后台确认正式样式已注入后撤掉。整页透明通常只持续 1～2 帧（CfT 157 本地实测约 10～20ms），超时 1.5 秒兜底撤掉。

## Considered Options

- **后台用 `storage.session` 按 tabId 记录**：被否决。CSS 属于文档而不是标签页，bfcache 后退、预渲染激活、跨页时序下会删错文档（REVIEW B5）。
- **后台监听 `webNavigation.onCommitted` 抢先注入**（uBlock Origin MV2 做法）：被否决。需要新增 `webNavigation` 权限，安装时提示"读取浏览记录"，与"零影响、最小权限"冲突。
- **启动时插 `<style>` 标签 / 改行内样式过渡**：被否决，理由同 ADR-0002（严格 CSP 站点拦截 `<style>`；行内样式被框架重渲染洗掉）。可构造样式表不是 DOM 节点、不受页面 CSP 限制，不存在这两个问题。
- **不做过渡、只靠用户样式表**：被否决。E2E 实测首个动画帧约在 5ms，SW 往返和一次 storage 读取都赶不上，被藏元素会闪现。

## Consequences

- SW 随时被回收都不影响还原与预览「放弃」；bfcache 恢复（`pageshow.persisted`）、预渲染激活（`prerenderingchange`）后内容脚本按存储重新同步。
- 已配置站点打开时会有 1～2 帧的空白（不是被藏内容），未配置站点不受影响（不注入）。启用站点时对已打开页面 `executeScript` 注入的场景不做过渡（页面已显示，过渡反而会闪白）。
- 过渡期内，页面作者 `!important` 且更高优先级的规则理论上可能盖过过渡样式；只影响几十毫秒，之后由用户样式表接管。
- 页面主世界脚本在过渡期内能看到 `document.adoptedStyleSheets` 里多出一张表。
- 标签页上的站点原标题仍可能在读到配置前的几毫秒内出现（内容脚本没有同步读取配置的途径）；页面内容可见的每一帧标题都已替换。
