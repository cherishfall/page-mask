# 站点名单制、每站点开关、未配置零影响

插件只对用户主动添加进站点名单的网站生效；每个站点一个开关（伪装态/原样态），状态按站点记忆；未配置的网站不注入任何脚本和样式、不显示任何界面元素。这是整个产品的骨架决策，源头需求是"用户不主动设置，插件对任何网站零影响"。

## Considered Options

- **全局总开关（老板键式），装完全局生效**：被否决。违背零影响核心需求，且无法表达"得到只在课程页伪装"这类站点差异。
- **内置常用网站预置规则包**：被否决。把网站改版的维护成本转嫁给插件作者，且商店用户的目标网站不可预测（详见 ADR-0003）。

## Consequences

- 权限模型走"按站点逐个授权"（Chrome 的可选主机权限），安装提示最小化，利于商店审核与用户信任。
- 悬浮按钮、失效体检等一切页面内界面只出现在已配置站点上。
