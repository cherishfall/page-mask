# PageMask 设计共识

本文档是 PageMask 的最终设计共识，是后续开发、建仓的唯一依据。术语定义见 [GLOSSARY.md](../GLOSSARY.md)，关键决策的背景与理由见 [docs/adr/](./adr/)。

- **项目名**：PageMask（中文别名"页面面具"）
- **一句话定位**：上班摸鱼伪装器——让非工作网站在一瞥之下"看起来不像它自己"
- **技术栈**：WXT + Vue 3 + TypeScript，Chrome Manifest V3，成熟组件优先
- **分发路径**：先自用（开发者模式加载）→ GitHub 开源 → Chrome Web Store 上架

## 核心原则（优先级从高到低，冲突时靠上者赢）

1. **零影响**：用户不主动设置，插件对任何网站零影响——无注入、无界面、无性能开销。
2. **零专业知识**：主流程 0 正则、0 通配符、0 CSS；一切专业写法折叠隐藏在「高级」后门里。
3. **反向操作完备**：能添加就能修改/删除/清空/导出；不做只进不出的设计。

## 数据模型

```
站点配置（按域名，一个网站一份）
├── 开关状态：伪装态 / 原样态
│     · 按站点记忆（关闭时是伪装态→重开仍伪装态；否则原样态）
│     · 同一网站所有打开的标签页联动切换
├── 伪装标题：默认"新建标签页"（不能设空白——空白会让 Chrome 显示网址反而泄露）
│     · 全局默认值可改，每站点可覆盖；快捷推荐一键填入
├── 伪装图标：默认空白透明（Chrome 自动显示通用地球图标）；可上传自定义图片
└── 隐藏规则 × N 条 —— 一条规则只藏一个东西，批量点选一次创建多条
      ① 藏什么：2-3 个候选选择器，由稳到险排序（语义属性 id/aria/data-* > 正常类名 > 结构路径），
         任一命中即算找到，全部失配才判失效
         · 生成时忽略 CSS-in-JS 机器乱码类名（css-、sc-、emotion- 等，React 站点重灾区）
         · 采用成熟库 css-selector-generator（天然输出候选序列）
         · 命中的同类元素一起藏，预览中可切换「只藏这个 / 一起藏」
         · 元素自动命名：无障碍标签 > 元素文本前几字 > 位置描述（如"顶部导航栏"）
      ② 怎么藏：收起方案 A/B/C（见下节），每条规则各选一种
      ③ 在哪藏：生效范围——整站（默认）/ 仅某类页面 / 排除某类页面
         · 零输入按钮生成（插件从当前网址自动推导"这类页面"），人话展示 + 网址示例
         · 失效体检只在该规则范围内的页面上进行
```

- 两条规则范围重叠且作用于同一元素：后创建的生效（v1 不做冲突检测界面）。
- 原样态 = 完全还原（标题、图标一并还原）。

## 收起方案

| 方案 | 效果 | 风险 | 定位 |
|---|---|---|---|
| A 彻底移除 | 元素消失，下方内容上移补位 | 布局重排可能变怪 | 默认首选 |
| B 原地留白 | 元素全透明+不可点，位置保留，结构不动 | 极少站点自己控制可见性 | A 不满意时 |
| C 遮罩覆盖 | 不碰网站任何样式，原位盖不透明"贴纸" | 滚动时贴纸要跟手 | 保底，永远可用 |

## 核心流程（设置向导）

1. **进入**：插件弹窗点「为当前网站设置伪装」（新站点）或「添加元素」（已有站点）。唯一入口，不做右键菜单、不做快捷键。页面处于伪装态时先临时还原全部规则再进入，退出后恢复。
2. **选择**：悬停高亮（轮廓+简要说明）→ 点击选中挂序号牌，再点取消 → 连续多选 → 工具条「选大一点 / 选小一点」调整层级（解决点选中内层文字的痛点）→ 防呆：选到整页大小元素时提示 → Esc 退出时已选元素需二次确认。
3. **预览**：全部选中元素统一按 A 应用 → 被移除元素原位出现幽灵标记（带序号虚线框，仅预览期间存在）→ 点标记调整：**换下一个方案**（A→B→C）/ **移出本次选择** / **同类元素切换**（只藏这个/一起藏）→ 界面提示"请滚动页面确认效果"（遮罩方案的问题只在滚动时暴露）。
4. **保存**：每条规则 = 元素名 + 方案 + 范围（默认整站，可此时设置）。新站点自动进入伪装态；已有站点维持当前开关状态（防在家配置时突然变样）。
5. **高级后门**：选择器文本可手动编辑，但**保存前必须现场命中至少一个元素**（uBlock 同款门槛），否则不允许保存。
6. **入口拦截**：chrome:// 内部页面、file:// 本地页面在添加名单时识别并提示"此类页面不支持"。

## 界面清单

| 界面 | 内容 |
|---|---|
| 插件弹窗 | 当前站点摘要（开关、规则数、体检红点）+「设置/添加元素」+「管理全部」 |
| 悬浮切换按钮 | 仅已配置站点显示；默认右下角小灰色胶囊、可拖动、记住位置；单击切换伪装态/原样态；右键 → 编辑伪装等菜单；本身设计得低调不显眼 |
| 页面内编辑面板 | 主编辑器（悬浮按钮右键进入）：列出**当前页面生效**的规则——换方案（即时预览）、改范围（零输入）、重选元素、删除；底部「添加元素」回向导；「高级」折叠区（选择器原文） |
| 管理页 | 全站点总览：每站伪装标题/图标设置、规则数、体检状态、一键清空（二次确认，列明影响）、导出/导入 |
| 首次引导 | 安装后 3 步图文：怎么给一个网站设伪装 |

## 标题与图标伪装

- 伪装态：改写 `document.title` + 替换 favicon，并监听页面 head 变化**自动补刀**（微信读书等 SPA 翻页改标题的瞬间压回）。参考实现 Tabee（chrome-tab-modifier）。
- 原样态：完全还原。
- 商店卖点素材：同类产品最大抱怨是"重开浏览器就忘"，本插件按站点持久化天然解决。

## 失效体检

- 时机：只在**伪装态**下采集与展示（原样态不体检——规则本就不应用，只会假警报）。
- 方式：打开页面时核对每条规则（限其生效范围内的页面）的候选选择器是否命中。
- 表达：人话（"'顶部导航栏'的隐藏规则最近在阅读类页面没找到目标，可能网站改版了"）+「去处理」按钮跳编辑。
- 明示局限：存在性体检 ≠ 视觉体检——元素命中但被网站挪了位置时检测不出，靠人眼复核。

## 实现铁律

- **注入通道**：隐藏一律走 `chrome.scripting.insertCSS`（浏览器用户样式表通道 + `!important`）。禁止改行内样式（会被框架重渲染洗掉）、禁止插入 `<style>` 标签（会被严格 CSP 站点拦截）。注入记录按文档由内容脚本持有，后台无状态；内容脚本 `document_start` 启动，首屏用可构造样式表做几十毫秒的过渡遮挡（ADR-0005）。
- **性能**：方案 A/B 零监听（纯样式表）；MutationObserver 仅用于标题/图标补刀、遮罩滚动跟随、SPA 路由变化时重评估范围。未配置站点零注入（按站点授权的 optional host permissions + 动态注册）。
- **存储**：`chrome.storage.local`；不用 `storage.sync`（公司/自购电脑互不串扰）。导出 JSON 带版本号字段供未来迁移。
- **权限**：最小权限集（storage、scripting、activeTab + 按站点可选主机权限），利于商店审核。
- **遮罩方案 C**：滚动/缩放时贴纸跟随元素（rAF）；z-index 冲突时允许用户感知并换方案。

## 已知边界（明示不解决）

- 标签页悬停缩略图预览、浏览器历史记录里的真实标题：浏览器自身行为，无法伪装。
- iframe 内、shadow DOM 内的元素第一版选择不了（检测到时给出提示）。
- 手机/iPad 的 Chrome 不支持扩展，天然不存在跨设备问题。
- GitHub 不作为任何配置分发通道（Dark Reader 教训）。

## 版本切分

- **V1（全部）**：上文全部功能，含首次引导、导出/导入（默认合并，可选整体替换）。
- **V2（视需要）**：办公软件风格图标预制包（邮件/文档/表格）。
- **永不做**：键盘快捷键（两次明确否决）、全局总开关、内置站点预置规则、远程配置订阅、右键菜单入口、uBlock 式免保存临时隐藏。
